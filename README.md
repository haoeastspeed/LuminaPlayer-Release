# 极光视频（Aurora Video）

一款 **零第三方依赖、单文件、开箱即用** 的 Windows 本地高清视频播放器。
纯 C++20 自研：容器解复用、编解码、音视频渲染全部独立实现，静态链接（/MT），
**无需安装 VCRedist、不附带任何 DLL**，双击即可播放。

## 特性

- **单文件免安装**：仅一个 `极光视频.exe`，绿色便携，不写运行库依赖。
- **解码正确性对标专业软件**：
  - 视频：H.264/AVC、H.265/HEVC、MPEG-4 Part 2（ASP / DivX / Xvid，**自研软解**）、VP9、AV1；
    支持 D3D11VA 硬件加速（H.264 / HEVC / VP9 / AV1）。
  - 音频：AAC、MP3、Opus（比特级精确）、AC3、DTS、FLAC、PCM。
- **极致渲染画质音质**：
  - D3D11 渲染管线，线性光（linear-light）高精度可分离缩放，RGBA16F 中间精度，杜绝色带与锯齿；
  - 正确的全范围 / 有限范围（Full/TV Range）转换；
  - HDR（PQ / HLG）自动识别与色调映射；
  - 高质量音频重采样与播放，多音轨切换。
- **字幕**：SRT、ASS/SSA 完整特效（样式、定位、绘图），MKV 内嵌字体自动加载，在线字幕搜索，字幕样式可调。
- **容器格式**：MP4 / MOV / M4V / 3GP、MKV / WebM、AVI、TS / M2TS、FLV、OGG、FLAC、IVF 等。
- **设置中心**：本地视频格式关联、多主题切换、播放与渲染参数、音轨/字幕默认项等。
- **播放稳定、启动快速**：极简启动路径，完善的异常与损坏流容错。

## 使用

1. 下载本仓库 Release 中的 `极光视频.exe`（或根目录同名文件）。
2. 双击运行，拖入视频文件即可播放；也可在「设置」中一键关联常见视频格式。

### 常用快捷键

| 操作 | 按键 |
|---|---|
| 播放 / 暂停 | 空格 |
| 快退 / 快进 | ← / → |
| 音量减 / 加 | ↓ / ↑ |
| 静音 | M |
| 全屏 | F / 双击 |
| 退出全屏 | Esc |

## 系统要求

- Windows 10 / 11（64 位）。
- 显卡支持 Direct3D 11（绝大多数核显 / 独显均可）。
